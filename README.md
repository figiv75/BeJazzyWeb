# BeJazzy website prototype

A dependency-free responsive prototype for the BeJazzy Slovenian mixed choir.

## Run

Open `index.html` directly in a browser. No Node.js or build step is required for this first prototype.

## Included

- Slovenian default language with English switcher
- Responsive public website: hero, about, events, media, join us, contact
- External ticket links
- Local admin CMS prototype for creating, editing, and deleting events
- Event edits persist in browser `localStorage`

## Replace before launch

The current event data, email address, social links, artwork, and copy are starter placeholders and should be replaced with verified BeJazzy content. The admin view is intentionally local-only and should be connected to a real authenticated backend for production.
